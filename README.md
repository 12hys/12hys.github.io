# rhys.codes

Personal blog built with [Hugo](https://gohugo.io/) and the [Coder](https://github.com/luizdepra/hugo-coder) theme. Deployed to GitHub Pages via GitHub Actions.

## Local development

```
hugo server
```

## Create a new post

```
hugo new posts/my-post.md
```

## Build

```
hugo --gc --minify
```
